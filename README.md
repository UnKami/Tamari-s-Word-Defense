# Tamari's Word Defense 🏰⚔️📚

A tower defense game meets word typing challenge! Defend Tamari's castle by typing missing letters in words before enemies breach your defenses. Features AI-generated word definitions, persistent progression via Supabase, and strategic tower placement.

## 🎮 Features

- **Tower Defense + Typing**: Unique gameplay combining strategy and word skills
- **User Authentication**: Secure login/signup with Supabase
- **Persistent Progress**: Auto-saves your game state, towers, and grimoire
- **AI-Powered Lexicon**: Word definitions generated by Google Gemini AI
- **Boss Battles**: Every 5th wave is an epic boss fight
- **Tower System**: SLOW and AUTOFILL towers to aid your defense
- **Beautiful UI**: Anime-inspired design with smooth animations

## 🛠️ Run Locally

**Prerequisites:** Node.js 18+

1. **Clone the repository:**
   ```bash
   git clone https://github.com/UnKami/Tamari-s-Word-Defense.git
   cd Tamari-s-Word-Defense
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Set up environment variables:**
   - Copy `.env.example` to `.env.local`
   - Add your API keys:
     ```env
     GEMINI_API_KEY=your_gemini_api_key
     VITE_SUPABASE_URL=your_supabase_url
     VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
     ```

4. **Run the development server:**
   ```bash
   npm run dev
   ```

5. **Open your browser:**
   Navigate to `http://localhost:3000`

## 🌐 Deploy to GitHub Pages

This repository includes automatic deployment via GitHub Actions.

### Setup GitHub Secrets:

1. Go to your repository **Settings → Secrets and variables → Actions**
2. Add these secrets:
   - `VITE_SUPABASE_URL` - Your Supabase project URL
   - `VITE_SUPABASE_ANON_KEY` - Your Supabase publishable key
   - `GEMINI_API_KEY` - Your Google Gemini API key

### Enable GitHub Pages:

1. Go to **Settings → Pages**
2. Under **Source**, select **GitHub Actions**

### Deploy:

Push to the `main` branch and GitHub Actions will automatically build and deploy!

## 📊 Database Schema

Built with Supabase PostgreSQL:

- **profiles** - User profile data
- **game_saves** - Health, coins, wave, towers
- **grimoire_entries** - Defeated words with AI definitions

All tables have Row Level Security (RLS) enabled.

## 🎯 How to Play

1. **Login/Signup** - Create an account to save progress
2. **Click READY!** - Start a wave of enemies
3. **Type missing letters** - Complete words to defeat enemies
4. **Build towers** - Click empty grid slots to place defensive towers
5. **Boss battles** - Type complete words to damage bosses
6. **View LEXICON** - Check your grimoire of defeated words
